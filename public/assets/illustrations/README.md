# Storyset illustrations (you download these, then drop them in this folder)

Source: https://storyset.com (free, SVG download, colors adjustable in their editor).
The free license requires attribution. Keep the footer credit "Illustrations by Storyset" in the site,
and double check the current license terms on their site before launch.

## Rules so everything matches
1. Pick ONE style (Amico, Bro, Cuate, Pana or Rafiki) and use it for every illustration.
2. In Storyset's color picker, set the main color to Violet #6C4BFF so they match the site.
3. Download as **SVG**. Optimize with SVGO if a file is over ~150 KB.
4. Save with EXACTLY these file names (the build prompt refers to them).
